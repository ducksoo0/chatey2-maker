사용 안내

글은 기본적으로 고정된 여백 안에 정렬돼요. 직접 배치를 켜면 드래그와 위치·너비 조절이 가능해요. 선택 테두리는 저장되지 않아요.

작업 저장 후 JSON 파일을 다시 열어 이어서 편집할 수 있어요. 사진은 서버에 업로드하지 않아요.

웹 글꼴을 처음 불러올 때는 인터넷 연결이 필요해요. PNG는 사용한 글꼴을 불러온 뒤 저장해요.
